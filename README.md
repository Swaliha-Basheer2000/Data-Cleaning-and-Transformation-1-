Data Cleaning & Transformation

This project demonstrates basic data cleaning and transformation techniques using Excel.

Techniques Covered

* Handling Missing Values – Identify and manage blank data.
* Correcting Inconsistent Data – Fix typos, spelling, and inconsistent formats.
* Removing Duplicates – Identify and remove duplicate records.
* Splitting & Merging – Separate or combine data across columns.
* Number Formatting – Standardize numbers, dates, percentages, and currency.
* Conditional Formatting – Highlight duplicates, missing values, and important data.

Objective

To transform raw data into a clean, consistent, and analysis-ready dataset.# Data-Cleaning-and-Transformation-1-
